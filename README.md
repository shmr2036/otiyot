# מעשה אותיות — דף נחיתה

ריטריט יום עם אמילי עמרוסי · חאן מצוקי דרגות, ים המלח · יום רביעי, 9 בדצמבר 2026 (נר חמישי של חנוכה) · 10:00–22:00.

דף נחיתה עצמאי (single-file HTML) בהשראת המבנה של [emilim.net](https://emilim.net/) ("חלון לרוח"),
עם פלטת צבעים של **אש/גחלת** שמתכתבת עם הקופי ועם הדימויים.

## הרצה / תצוגה מקדימה
פותחים את `index.html` בדפדפן:
```bash
xdg-open index.html
```
(הפונטים — Frank Ruhl Libre + Assistant — נטענים מ-Google Fonts, אז צריך אינטרנט לתצוגה המלאה.)

## קובץ יחיד לשליחה (וואטסאפ)
```bash
python3 tools/build_share.py   # -> share/maaseh-otiyot.html
```
יוצר קובץ HTML אחד שהתמונות והפונטים מוטמעים בתוכו (`tools/vendor/`), והסרטונים מוצגים בו כקישורים ל-Vimeo. צריך להריץ מחדש אחרי כל שינוי ב-`index.html`.

## עדיין להשלים ⚠️
- **פיקסל מטא** — להדביק את הקוד במקום המסומן ב-`<head>` (`Meta Pixel`) כשיתקבל.
- **אירוח** — לפרסם בנתיב נפרד (למשל `emilim.net/maaseh-otiyot/`) בלי לגעת בדף הקיים של חלון לרוח. כל הנתיבים בדף יחסיים, אז מספיק להעלות את `index.html` ואת `assets/` לאותה תיקייה.

ההמלצות והסרטונים (Vimeo) לקוחים מדף חלון לרוח באישור. החלטות הלקוח מתועדות ב-`PRODUCT.md`.

## מבנה הדף
Header קבוע → Hero (פוסטר כותרת + תאריך/שעות + CTA) → היכרות עם אמילי + דיוקן (סקשן כהה) →
"מה מחכה לנו?" (3 כרטיסים) → גלריית חאן מצוקי דרגות → באנר מניפסט (טקסט רץ ברקע) →
מחיר (הדגשת הרשמה מוקדמת 990→1190) → שאלות ותשובות (אקורדיון, 7 שאלות) →
סיום פואטי + כפתורי הרשמה/ווטסאפ → פוטר → כפתור ווטסאפ צף.
